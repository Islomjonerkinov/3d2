# 🏙️ Цифровой и инклюзивный город

Этот веб-сайт был разработан в качестве школьного проекта для исследования вопроса: **«Как технологии могут сделать городскую среду удобнее для всех жителей?»**

Проект демонстрирует концепцию "умного города", где цифровые решения делают жизнь людей более комфортной, безопасной и доступной, особенно для детей, пожилых людей и людей с ограниченными возможностями.

## 🚀 Основные возможности

Сайт представляет собой современную образовательную платформу с использованием передовых принципов UI/UX дизайна:

- **🌐 Полная адаптивность**: Сайт корректно отображается на всех устройствах — от смартфонов до широкоформатных мониторов.
- **🌗 Динамическая тема**: Поддержка светлого и темного режимов с плавным переходом для максимального комфорта пользователя.
- **🖱️ Интерактивная карта**: Интерактивная демонстрация объектов умного города с информационными окнами.
- **📊 Анализ решений**: Наглядная таблица, сопоставляющая реальные городские проблемы и их технологические решения.
- **🎨 Современный дизайн**: Эстетика в стиле Apple с использованием мягких теней, плавных анимаций и профессиональной типографики.

## 🛠️ Технологический стек

Проект реализован с использованием чистых веб-технологий без использования платных библиотек:

- **HTML5**: Структура и семантика контента.
- **CSS3**: Продвинутая стилизация, CSS-переменные (tokens), Flexbox, Grid и сложные анимации.
- **JavaScript (ES6+)**: Логика переключения тем, интерактивность карты и плавный скроллинг.

## 📖 Структура проекта

1. **Главная страница**: Тезис проекта и визуальное введение.
2. **Электронные услуги**: Обзор цифровизации госуслуг (медицина, ЖКХ, образование).
3. **Доступная среда**: Решения для инклюзивности (звуковые светофоры, пандусы).
4. **Безопасность**: Умное освещение и принципы кибербезопасности.
5. **Интерактив**: Живая демонстрация работы элементов умного города.
6. **Проблемы и решения**: Сводная таблица эффективности технологий.
